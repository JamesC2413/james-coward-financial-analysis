ABOUT

About this project

My name is James Coward, and I created this website for an Entrepreneurial Finance project at Rogers State University.

The project demonstrates how historical adjusted closing prices can be converted into understandable measures of investment return and risk. Bloom Energy is the selected security, while SPY represents the broader market for comparison.

Project purpose

  • Calculate financial measures correctly
  • Explain each result in plain language
  • Provide a transparent, repeatable method
  • Demonstrate responsible use of AI in development

RESULTS

Financial measures

Holding-period return—

Total BE return over the selected period.

Annualized return—

Compounded BE return expressed per year.

Annualized volatility—

Daily return variability scaled by √252.

Beta relative to SPY—

BE's sensitivity to SPY's daily returns.

Excess return—

BE holding-period return minus SPY's.

SPY benchmark return—

Market comparison shown for transparency.

Interpretation

Methodology and formulas

Holding-period return
(Ending adjusted close ÷ Beginning adjusted close) − 1

Annualized return
(Ending price ÷ Beginning price)365.2425 ÷ elapsed days − 1

Annualized volatility
Sample standard deviation of daily returns × √252

Beta
Covariance(BE returns, SPY returns) ÷ Variance(SPY returns)

Excess return
BE holding-period return − SPY holding-period return
